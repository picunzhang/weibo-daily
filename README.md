# 七色墨水屏控制台 · 7.3" E-Paper Studio

专为 **7.3 寸七色电子墨水屏（Spectra 6 / 七色）** 打造的网页控制与内容投送工具。
通过浏览器蓝牙（Web Bluetooth）将图片、天气、每日热搜、日历、网页截图等内容无线推送到墨水屏设备，
支持 **A / B 双面** 独立或异显投送。

> 本项目根目录 `index.html` 仅适配 7.3 寸七色屏（`800×480`），不兼容其它尺寸/驱动。
> 旧版 4.2 寸方案保留在 `v1.5/`（独立 demo，非本项目的目标设备）。

---

## ✨ 功能特性

- **蓝牙传图（双协议）**：兼容 Web 协议与 APP 协议（自动识别），支持 MTU 协商、LZ77 压缩、
  交错分包、A/B 双面同步与异显。
- **画板工具**：画笔、橡皮、文字、图片裁剪、旋转、课表、待办、名片、WiFi、日历（含农历）等。
- **七色抖动取模**：将真彩图像映射为七色墨水屏调色板（`黑/白/红/黄/绿/蓝/橙`）。
- **内容投送（A/B 双面）** —— 本次重点增强：
  - **A 面 · 天气**：对接和风天气 API，生成完整 / 简洁两种版式的天气卡片。
  - **B 面 · 每日热搜**：接入微博 / 百度 / 抖音 / 知乎 / B站 等免费公开热搜榜，
    在线失败自动回退内置示例数据（离线不崩）。
  - **B 面 · 日历**：生成本月日历，含农历、节假日、节气。
  - **B 面 · 网页投送**：输入网址调用截图服务生成图片推送到墨水屏；
    也支持本地图片上传（始终可用，无 CORS 限制）。
  - **一键投递**：生成预览后，可分别投递到 A 面 / B 面，或「AB 异显」同时投递。

## 🚀 快速开始

### 1. 运行环境
- 浏览器：**Chrome / Edge（桌面端）** 或 Android Chrome（需支持 Web Bluetooth）。
- iOS 可使用 **Bluefy** 等支持蓝牙的浏览器。

### 2. 打开控制台
直接双击 `index.html` 即可；或启动一个本地静态服务器（推荐，避免个别浏览器对 `file://` 的限制）：

```bash
# 任选其一
python3 -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080/`。

### 3. 连接设备并投递
1. 点击「连接」搜索并连接墨水屏（设备名通常以 `NRF_EPD_` / `EPD_` / `YSBadge2` 开头）。
2. 进入 **「内容投送 · A/B 双面」** 面板：
   - **A 面**：填写和风天气 Host / Key / 城市，点击「获取天气并预览」→「投递到 A 面」。
   - **B 面**：选择「热搜榜 / 日历 / 网页投送」子页签，生成内容后「投递到 B 面」。
   - 或点击「AB 异显投递」一次性把 A 天气 + B 热搜/日历/网页 同时下发。
3. 等待设备刷新完成（电脑端解压/刷新耗时较长，请耐心等待）。

## 🔑 配置说明

### 天气（A 面）
- 在 [和风天气开发者控制台](https://dev.qweather.com/) 申请 API Key，填入 Host 与 Key。
- Host 形如 `xxxxxx.qweatherapi.com`，配置会保存在浏览器 `localStorage`。

### 每日热搜（B 面）
- 默认使用免费聚合接口 `api.vvhan.com`，无需 Key，开箱即用。
- 若接口不可达，自动回退到内置示例数据，保证预览不空白。

### 网页投送（B 面）
- 默认截图服务：`https://api.vvhan.com/api/screenshot?url=<网址>`。
- ⚠️ 第三方截图服务若未返回 CORS 头，浏览器会因画布被污染而无法取模发送；
  此时请改用「本地图片」上传按钮（上传本地图片不受 CORS 限制，始终可用）。
- 可在「截图API(可选)」中替换为自建/其它截图服务地址。

## 📝 说明 / 限制

- 墨水屏刷新较慢，复杂画面首次刷新等待时间更长，纯白画面最快。
- 网页投送依赖外部截图服务，稳定性取决于第三方接口；生产环境建议自建截图服务。
- 本项目为纯静态前端，所有数据均在浏览器本地处理，不上传任何服务器（除调用天气/热搜/截图等公开 API 外）。
